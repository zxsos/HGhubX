# HGhubX v3.1.2

HGhubX 3.1.2 正式版：正式纳入 HarmonyOS 鸿蒙未签名安装包（自签可用），新增视频加载 DNS 并发竞速与 Rust 媒体代理层 HLS 后台并发预取，统一全端网络、视频源与播放器错误代号层，并修复安卓端返回退出后重新打开闪退与切后台继续拉流问题；覆盖 Windows、macOS、Linux、Android、iOS 与 HarmonyOS。

## 新增与优化
1. **正式纳入 HarmonyOS 鸿蒙自签版（#283）**：同步标准版全部功能与界面，随本版同步提供 `HGhubX_3.1.2_ohos_arm64_unsigned.hap` 未签名安装包；前端自动识别 HarmonyOS 平台，内置更新检查支持优先匹配 `.hap` 产物。
2. **视频加载与首播提速**：
   - 底层客户端构建与域名解析引入同主机 single-flight 合并与 900ms 系统 DNS / 阿里 DoH 并发竞速（保留严格模式既有 IP 与重定向安全校验），降低冷启动并发排队与弱网 DNS 阻塞。
   - Rust 媒体代理层新增 HLS 后台并发预取：解析播放列表后即并发预热加密 Key、初始化片段与前 2 个分片，播放期间按当前分片自动预取后续 `N+1` / `N+2` 分片（全局并发限流 3，切线、切集或清缓存即时取消），显著提升起播与续播缓冲速度。
3. **统一错误代号层与历史同步自动重试**：
   - 后端网络请求、视频源脚本与播放器错误统一收口为带语义代号的可读提示（如 `NET_TIMEOUT`、`NET_DNS`、`NET_PROXY`、`HTTP_*`、`SRC_*`、`MEDIA_*`），不再向界面直接暴露原始英文报错、请求 URL 或 QuickJS `eval_script` 调用栈。
   - 「观看历史」接口（`api_account_history`）纳入只读瞬态超时自动重试，减少「我的」页同步失败。
4. **桌面端与移动端 UI/UX 全面打磨**：
   - 桌面端按面板容器宽度自适应至 960px（有效宽度增至 ~904px，频道/标签/帖子/「我的」统一 5 列对齐），分类快捷入口收敛为单行 5 卡均分，横向片架新增边缘渐隐与悬停翻页按钮，侧栏进入二级页保留来源高亮，根级「设置」「排行榜」去冗余返回键，设置分组新增图标与实时状态摘要且双选择器等宽对齐。
   - 移动端横向片架通栏延展消除右侧截断感，修复浅色主题帖子操作胶囊对比度与「我的」页「视频/帖子」激活态反转，收紧圆角至 12 / 20 / 28px 三档，统一所有抽屉 44px 关闭键、描线图标与滚动标题分隔线，播放异常卡片上移并升级毛玻璃胶囊，排序/筛选菜单选中项满足 WCAG AA（≥ 4.5:1）对比度。

## 修复
1. **安卓端返回退出后重新打开闪退**：根页面双击返回直接触发 `finishAffinity()` 后，延迟的 `onDestroy()` 进程退出逻辑会在短时间重开时误杀新实例 -> 改为通过安卓原生桥调用 `moveTaskToBack(true)` 退回后台，避免重开闪退。
2. **应用切入后台后仍继续拉取视频分片**：退回后台时播放器未及时停流导致后台流量消耗与恢复状态错乱 -> 监听页面不可见事件同步暂停并调用 `hls.stopLoad()`，回到前台后按原播放意图或显式暂停状态恢复。
3. **详情/选集抽屉滑动方向错乱与滑到相关推荐后无法滚动**：强制横屏旋转态（`.fs-landscape`）下，选集无法右滑回详情、详情下滑会误切选集，且详情上滑至「相关推荐」后整页卡死无法回滑 -> 为 `PanelSwipeArea` 补齐 90° 旋转坐标换算、主轴锁定、横向 `preventDefault` 与 click 抑制，并在旋转态对调 `.scroll-x` 的 `overscroll-behavior` 轴向以恢复纵向滚动链。
4. **图文帖子仍显示未来时间**：部分帖子排期/置顶或异常时间戳穿透显示为未来日期 -> 将有效时间上限收紧至当前时间 + 5 分钟并对全部日期时间格式执行严格校验，自动跳过未来值回退有效字段或隐藏。
5. **各页面弹出菜单返回键穿透与滑切后误吞点击**：频道排序、标签状态、作品状态、收藏筛选与桌面倍速菜单展开时按 `Escape` 或安卓返回键可能直接退页/退全屏，排行榜/频道/帖子滑切后 360ms 内立即点「返回」或卡片会被吞掉，帖子页横滑易误点进详情 -> 统一为全部弹出菜单补齐 `registerOverlayBack` 与捕获阶段 `Escape` 拦截（含 `inert` 与内嵌全屏让步），并在每次新触摸/指针按下时清除上一次滑切遗留的 click 抑制窗口，统一 `PostsPage` 至 `useTabSwipe` 并修复「我的」页下拉刷新 `touchcancel` 误触发。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb` 与 `.rpm`；Android 提供按 ABI 分包签名 APK（`versionCode=3001002`）；iOS 提供已 ad-hoc 签名的 `.ipa`（需自行重签侧载安装）；HarmonyOS 提供未签名的 `HGhubX_3.1.2_ohos_arm64_unsigned.hap`（需自行签名后安装）。
- 支持从 `v3.0.0` / `v3.1.1` 直接覆盖安装，所有已导入的视频源、收藏、观看记录与偏好设置均予保留。
